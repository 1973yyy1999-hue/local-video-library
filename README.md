# 影库

面向 Windows 10 / 11 x64 的本地视频整理器：封面墙、模糊搜索、悬停预览、收藏、标签、全屏与悬浮小窗。

## 下载

前往 **[Releases](https://github.com/1973yyy1999-hue/local-video-library/releases)**，下载 `Yingku-1.1.0-Windows-x64.zip`，完整解压，打开 **影库.exe**。仅提供免安装版，不需要安装或下载 Source code；不要单独移动 EXE。

升级前退出旧版。包名、窗口名和 EXE 已改为“影库”；内部应用标识与数据目录保持兼容。旧提交与更新说明保留在 [更新记录](CHANGELOG.md)。程序尚未使用商业代码签名。

## 改名和移动的边界

**首次升级后，在整理文件之前完成一次扫描。** 文件存在时才有机会保存原始指纹；旧版已移走且无指纹的数据无法凭空恢复关联。

指纹由文件大小和头尾最多各 64 KiB 的 SHA-256 构成；小文件不重复读取重叠部分。首次或变化后的文件需要建立指纹，已有指纹且大小、修改时间未变的文件不重复读取内容。并非读取整个视频，亦不是全文件一致性校验。

完整扫描后，仅对唯一对应的旧、新记录自动迁移。副本重复、扫描中断、读取失败等歧义不强行合并。有收藏、标签、进度、已看或播放记录的未匹配文件保留为离线；无用户数据的已删除记录可清理。移动目标须位于已添加来源，移出来源后须添加新的父文件夹再扫描。

同名路径被不同内容替换时，新文件不继承旧文件的用户记录。重新定位来源会对有指纹的文件进一步验证内容，旧记录没有指纹时仍使用路径与大小并要求确认。

默认不接收 `.ts`、`.mts`、`.m2ts`，避免 TypeScript 等同名扩展名被当成视频。旧索引中的对应记录留在 `excludedVideos` 中，不进入列表或系统播放器入口；MPEG-TS 文件支持暂缓。

## 磁盘与播放

- 视频留在原处；移除来源只移除索引，不删除视频。
- 默认一个媒体任务，适合机械盘。可选 2/4 并发；播放时暂停扫描和媒体生成。
- 封面与预览合计默认上限 **512 MB**，可选 128/256 MB/1/2 GB，支持清理和换位置。**不包含软件体积、索引或运行内存。** 优先淘汰预览，但封面本身超额时仍会淘汰较旧封面。
- Windows 默认缓存 `%LOCALAPPDATA%\LocalVideoLibrary\MediaCache`；索引、设置及历史备份在原 userData 目录（通常 `%APPDATA%\local-video-library`）。免安装包不是“所有数据跟随 EXE”的便携数据模式。
- 数据目录包含 `library.json`、`.bak`、`changes.jsonl`、`settings.json`，另保留两代压缩索引历史，每代上限 32 MB。迁移/备份时先退出程序，再复制整个数据目录。
- Chromium 内置播放器仍存在 HEVC、AC3/DTS 等兼容性限制；右键可用系统默认或自选播放器，保留全屏和画中画。此次不加入需要复制整个媒体文件的音频兼容缓存，也未加入外挂字幕。
- 缓存 LRU 时间戳每文件最多每分钟更新一次，正常退出补齐；异常断电可能丢失这一分钟内的访问顺序。

## 开发

需要 Node.js >= 22.12。依赖版本锁定，Windows CI 使用 npm ci。

```sh
npm ci
npm start
npm test
npm run test:e2e
npm run dist:win
```

构建只生成 ZIP。推送 main 会测试和打包；推送 v* 标签会在通过测试后发布 Release，正式下载不再依赖 30 天 Actions 附件。生成的第三方声明目录来自固定依赖和实际二进制；`scripts/make-icon.py` 从现有品牌几何生成 Windows 图标，无额外 Python 依赖。

测试覆盖移动/改名、重复副本、离线恢复、指纹迁移、缓存持久化和淘汰、并发与限额、设置竞态、搜索、窗口菜单、全屏、小窗、侧栏状态与 Windows 打包。Windows runner 不代替 Win10 多机械盘、各种编码和老集显实测。
