# 拾影 · Local Video Library

面向 **Windows 10 / 11（64 位 Intel / AMD）** 的中文本地视频整理器。添加硬盘上的视频文件夹，通过封面墙、模糊搜索、悬停预览找到想看的内容。

## v0.3.0：统一窗口与菜单、可靠的封面队列

- **一体化窗口栏**：顶部与软件同色，提供拖动、最小化、最大化/还原和关闭；保留 Ctrl + / Ctrl - / Ctrl 0 缩放。
- **统一右键菜单**：卡片、播放画面和全屏共用应用菜单，支持键盘方向键和 Esc；菜单明确称为“系统默认播放器”，不假定使用哪款软件。
- **设置集中**：悬停预览移到“设置与缓存”，立即保存开关；主题可跟随系统或选择浅色、深色。
- **封面有状态**：区分等待、加载、失败和离线；快速滚动跳过屏幕外排队任务，优先处理刚进入视野的卡片。
- **失败可恢复**：忙碌、超时和空间不足等临时错误按 30 秒到 5 分钟间隔退避，重新可见时重试；明确损坏的文件保留失败状态。设置中可批量重试，清理缓存也会清除失败记录。
- **谨慎重新定位**：选择目录后先核对相对路径、文件类型和大小，显示匹配数量；零匹配或已有文件不一致时拒绝，确认后才改路径。它不是内容哈希校验，也不会自动猜测盘符。
- **可选并发**：默认 1 个媒体任务，适合机械盘；可选择 2 或 4 个。并发任务共享缓存总额度，生成前计入临时空间预算，播放时全部暂停。
- **历史索引**：扫描和重新定位前保留两代压缩历史，每代最多 32 MB（合计最多 64 MB，另计临时写入空间）。可在设置中恢复最近一代；保留现有 `.bak` 用于写坏恢复。备份不包含原视频。
- **播放与稳定性**：重看不清除已看完标记，可右键标为已看/未看；界面刷新或崩溃时复位播放锁；未探测过编码的文件也有兼容性说明。
- **滚动绘制**：移除卡片角标上的背景模糊，提高辅助文字可读性。集显帧率与实际对比度仍以目标电脑测量为准。

完整版本轨迹见 [CHANGELOG.md](CHANGELOG.md)，审阅取舍见 [v0.3 审阅处理](docs/REVIEW-0.3.md)。旧提交、旧说明均保留，不强制推送改写历史。

## v0.2.0：机械硬盘与播放体验

- **机械硬盘优先**：扫描阶段先展示文件名和卡片，结束后补充封面；媒体任务串行执行，首屏可见卡片才读取视频；打开播放器后暂停扫描和后台生成，避免争抢机械硬盘。
- **系统盘占用可控**：封面和预览默认合计最多 **512 MB**，可改为 128 / 256 MB / 1 / 2 GB。缓存接近上限自动淘汰较久未使用内容，支持显示占用、清理和更换位置。视频原文件不复制到系统盘。
- **少写盘**：进度、标签、收藏、媒体信息按条合并写入小型增量日志；进度每 15 秒、暂停及关闭时保存，退出前等待落盘。整库快照仅在扫描、来源变动或增量日志超过 8 MB 时整理。v0.3 另增加有容量上限的操作前历史备份。
- **播放**：修复自有页面全屏权限，增加全屏按钮、`F` 全屏 / `Esc` 返回；保留原生视频控件和**画中画悬浮小窗**，并提供独立按钮。
- **PotPlayer**：在视频卡片或播放画面上右键，选择系统默认播放器。若 Windows 默认播放器已经是 PotPlayer，会直接用它打开。也可手动选择其他已安装的播放器。不会将 PotPlayer 打包或当作内置播放内核。
- **界面**：浅色半透明磨砂玻璃风格、统一 SVG 图标、提高字号与对比度；是应用内的玻璃视觉，不依赖 Win11 桌面材质。`Ctrl +` / `Ctrl -` 可以缩放界面。
- **不再闪封面**：收藏、进度及标签就地更新，复用搜索索引与卡片；搜索范围始终可见，一键搜索全部视频；支持标签筛选、时长排序、观看进度和已看完标记。
- **恢复与重试**：来源文件夹旁的更多按钮可以重新定位盘符变化后的路径；保留视频编号、收藏、标签和进度。坏文件失败结果会记住，通过右键主动重试。索引备份可恢复，损坏文件会保留。

## 下载与使用

1. 打开 [Actions / Windows build](https://github.com/1973yyy1999-hue/local-video-library/actions/workflows/windows.yml)，选择最新绿色成功运行。
2. 在 **Artifacts** 下载 `LocalVideoLibrary-Windows-x64`，通常需要登录 GitHub。
3. 解压下载文件；其中 `LocalVideoLibrary-0.3.0-win-x64.zip` 为免安装版。再次完整解压，双击 `Local Video Library.exe`。不要只复制 EXE。
4. 也可以使用同目录的 `.exe` 安装包。
5. 添加一个或多个视频文件夹。首次补充封面需要读取原视频，已有缓存直接从缓存盘读取。

正式版本也可能出现在 [Releases](https://github.com/1973yyy1999-hue/local-video-library/releases)。目前无商业代码签名，Windows 可能提示未知发布者。

## 缓存与数据

- Windows 媒体缓存默认位于 `%LOCALAPPDATA%\LocalVideoLibrary\MediaCache`，避免放进 Roaming 漫游目录。旧版媒体缓存启动时会在额度内整合，不保留两套有效缓存。
- **512 MB 是媒体缓存额度，不是整个软件安装体积，也不是 RAM 上限。** 程序本体、Electron 运行内存、索引和必要备份另计。关闭不需要的预览可以进一步减少读取与内存使用。
- 额度检查会为单个生成任务预留 20 MB；临时输出结束或失败后清理。进入“设置与缓存”可设置更低额度或迁到其他磁盘，已有媒体缓存会随之移动。
- 索引和设置仍在 Electron 的 userData 目录，Windows 通常为 `%APPDATA%\local-video-library`。`library.json` + `.bak` 是快照，`changes.jsonl` 是小批量更新，`settings.json` 是配置。迁移前退出程序并备份整个目录。
- 原视频只读；移除来源仅移除索引。升级到 v0.3.0 自动读取 v0.1 / v0.2 索引，建议首次升级前备份数据目录。
- 重新定位要求选择原来源文件夹的新位置、保持相对目录结构；存在但大小不一致的文件会拒绝迁移，缺失文件保留为离线。此功能不是全盘内容哈希匹配，不能自动识别任意改名或移动。
- 启动自动扫描默认关闭，可在设置开启。扫描过程中可以停止；离线盘保留原有记录。扫描跳过符号链接、隐藏目录和系统回收站。

## 播放与搜索范围

- 内置播放器依赖 Chromium 解码；某些 HEVC、AVI、AC3、DTS 文件可能无法播放或无声。已探测到的编码会显示兼容性提示，未探测的文件显示通用提示，可右键使用系统播放器。此版没有加入全片自动转码，以免长时间占用 CPU、机械硬盘和系统盘。
- 悬停 0.65 秒后生成最长 6 秒静音预览；首次需要等待，后续读取缓存。用 Tab 移动焦点不会触发生成，系统选择减少动态效果时不自动预览。
- 搜索文件名、相对目录和手动标签，支持中文部分关键词与英文错字容错，多词使用空格分隔；不识别画面、语音、字幕，也不提供拼音搜索。
- 玻璃外观与全屏、小窗已加入自动化验证；GitHub Windows runner 不等于 Win10 实机。多块真实机械盘、长路径、HDR、各种编码与系统播放器仍需在你的设备上验收。

## 开发与测试

需要 Node.js 22.12+（或更新受支持版本）。首次安装需要访问 npm 和 GitHub。

```sh
npm ci
npm start
npm test
npm run test:e2e
npm run dist:win
```

单元测试包含离线恢复、增量保存、缓存配额、损坏恢复、路径重新定位、失败去重、串行任务与视频 Range 请求。Windows E2E 验证搜索、封面、悬停、全屏、画中画、系统播放器调用、缓存设置、标签与重启恢复，并保存截图。构建会裁剪 ffprobe 非 Windows x64 二进制。

推送 `main` 会自动测试并生成 ZIP / NSIS，Artifacts 保留 30 天。`v*` 标签可触发 Release 发布。仓库固定了依赖版本并使用 `npm ci`。
