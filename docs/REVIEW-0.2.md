# v0.2 审阅反馈处理

按实际使用反馈优先实现机械硬盘、系统盘额度、全屏、外部播放器及玻璃外观。

已采纳并验证代码路径：增量扫描展示；合并单条写入与退出 flush；复用 Fuse 索引；收藏局部更新；重新定位来源路径；编码提示；失败记忆与手动重试；索引备份恢复；时长 h:mm:ss；搜索范围与搜全部；卡片进度及标签筛选；键盘不触发预览；SVG 图标、字号和缩放；重复/重叠来源反馈；可选启动扫描；缓存配额/清理/移动；剔除 attached_pic 预览流；ffprobe 跨平台包裁剪。

未直接采用：

- 16–32 路并发扫描和全库后台预览：不适合当前多块机械盘、SSD 占用优先的约束。
- 全库内容哈希匹配：会额外读取所有视频，先提供明确的路径重新定位。
- SQLite：本轮使用快照 + 合并单条日志，先消除写放大，避免为迁移增加原生模块依赖。仍会在启动及扫描结束传递一次整库快照，超大规模需要进一步测量。
- 自动全片转码、嵌入 PotPlayer：用户已经将 PotPlayer 设为默认播放器，本轮直接系统调用并保留现有画中画。
- 商业签名、完整字幕/音轨系统、批量管理和任意文件移动追踪：未纳入此次改动。

不把代码检查或 Windows Server runner 结果当作 Win10 机械硬盘实测。实际吞吐、CPU、内存、HDD 寻道与磁盘峰值仍需用户设备数据。
