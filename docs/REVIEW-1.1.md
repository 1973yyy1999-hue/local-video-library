# v1.1.0 审阅处理

## 产品要求

名称统一为影库；侧栏收起并记忆状态；卡片悬停上浮及阴影；精简宣传、技术解释和重复说明，保留影响用户判断的错误/离线/删除/恢复提示。仅构建免安装 ZIP，通过 Releases 下载。既有 Git 提交、审阅文件和版本记录不覆盖删除。

## 已核对并处理

- 路径哈希身份不能追踪移动属实。建立大小与头尾样本哈希，并在完整扫描末尾进行唯一配对。必须提前保存旧指纹，无法照搬“文件消失后再读旧路径”的建议；首次升级扫描会为仍在原位的文件补齐。新记录使用独立随机编号，旧编号沿用。带用户数据的未匹配记录保留离线，重复样本不自动配对。
- `.ts/.mts/.m2ts` 默认不再索引，系统播放器入口也拒绝；旧记录另行保留，避免把旧用户记录彻底抹去。
- LRU 持久化属实：缓存命中时每分钟至多更新时间戳一次，退出/迁移前刷新剩余访问时间；淘汰时预览优先，保持总额度不变。
- 增加五次临时失败上限，表现为需手动重试，不把临时错误谎称为文件损坏。
- settings.json 保存通过独立 Promise 链串行写临时文件、同步并替换；校验 autoScan、playerPath、缓存目录和所有偏好字段。
- 搜索先用预处理文本匹配，无结果才构建/调用 Fuse；扫描批次刷新由 500ms 改为 1500ms。
- 当前 checkpoint 实际只调用一次 JSON.stringify，审阅此条不准确。新增日志/快照文件同步；保留历史备份以应对逻辑错误，不宣称 fsync 可以解决所有断电或逻辑损坏。
- 将用户偏好迁入 settings.json，保留旧 localStorage 一次性迁移。
- 配置 Windows ICO、启用 EXE 资源编辑（不等于代码签名），包内补充组件许可证及实际 FFmpeg/FFprobe 版本、构建信息、版权声明。

## 本轮暂缓

- SQLite/FTS、Web Worker、全面模块拆分与格式化依赖：先消除明确性能瓶颈；现有查询仍在界面线程，极大库或容错查询仍可能卡顿。
- 缓存分区/WebP：先采用预览优先淘汰，避免抬高默认系统盘额度与额外迁移。
- 大范围封面预取、深处选帧、黑帧检测：会扩大机械盘读取，此版保留按当前可见区域生成。
- 音频 AAC 兼容模式和字幕：即使复制视频流仍需完整读写并占用接近原片的空间，需单独设计磁盘位置/额度/取消/回收机制；已有系统播放器入口继续可用。
- 改回原生窗口栏：用户此前要求统一风格，且目标仍是 Win10，本版保留自绘栏。
- 子目录树、标签总览、拖拽导入、继续观看入口、重复视频管理：作为独立功能后续安排，指纹机制不直接当成准确去重依据。
- Dependabot 和自动安全审计配置：此次未增加新的自动依赖更新工作流。
