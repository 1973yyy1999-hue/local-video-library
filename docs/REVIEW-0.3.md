# v0.3 审阅核对与处理

用户实际反馈优先：一体化窗口栏、统一右键菜单、将悬停预览移入设置。保留既有悬浮小窗、全屏、机械盘默认单任务、缓存额度和 Git 提交历史。

## 经代码核对后处理

1. 原封面队列捕获错误但不显示：新增等待、加载、暂时不可用、不可用与离线状态。
2. 原失败记录仅按指纹保存，无失效期限：区分明确损坏与临时错误，临时错误采用退避时间，旧版失败记录自动允许重试；支持批量清除失败，清缓存同步重置。
3. 原观察器首次可见便取消观察，FIFO 排队不校验当前可见性：持续观察；离屏移出队列；启动任务前复查几何位置；最新可见优先。已经开始的单个任务可结束，不反复杀进程。
4. 原重新定位接受零匹配：拆成只读核对与确认提交；检查相对路径、大小、文件类型；零匹配拒绝，部分匹配明示数量；确认时重新核对，不信任前端提交的路径。
5. 原媒体并发固定为 1：增加 1/2/4 档，默认仍为 1，不自动判断盘型。并发共享缓存预留空间，不各自占用一份上限。
6. `.bak` 的确是当前快照镜像：保留崩溃恢复机制，另存两代操作前压缩历史，提供恢复入口。每代 32 MB 上限，超限时明确阻止操作，而不无限增长。
7. 原播放锁缺少界面生命周期复位：监听主页面导航及渲染进程退出，释放播放锁并保存进度；异常退出提供重新打开界面。
8. 原进度保存每次覆盖 watched：普通重看进度不写 false；手动菜单支持标记，在当前播放会话内尊重手动结果。
9. 原文案写死 PotPlayer：通用界面统一写系统默认播放器；未检测编码时显示通用说明。为避免播放前增加机械盘随机读，不强制额外探测整个视频库。
10. 原强制浅色、角标逐个模糊属实：新增系统/浅/深主题，移除卡片角标模糊，调整辅助文字颜色。审阅给出的 4.3:1 是估算，不能据此宣布全部界面达标；集显性能也未实测。
