影库 v1.1.0 · Windows 10 / 11 x64

本版只提供免安装版。下载 `Yingku-1.1.0-Windows-x64.zip`，完整解压后打开 `影库.exe`。无需下载 GitHub 自动附带的 Source code。

- 名称改为“影库”，增加可收起的侧边栏，并记住展开状态。
- 视频卡片悬停上浮、阴影和轻微封面缩放；精简首页与设置中的重复说明。
- 新增内容指纹匹配，改名或在已添加来源间移动后保留收藏、标签、进度及编号。
- 缓存优先保留封面，使用顺序持久化；临时失败连续 5 次后等待手动重试。
- 默认不索引 `.ts`、`.mts`、`.m2ts`；设置保存串行化，搜索先走快速文字匹配。
- 增加 Windows EXE 品牌图标，免安装包附第三方许可证、实际媒体工具版本与源码获取说明。

升级：退出旧版，再完整解压新版本。内部数据目录与旧版保持一致。

首次使用新版，请在文件尚未改名/移动时完成一次扫描，建立内容指纹。旧版已移走且从未建立指纹的文件无法可靠自动配对；已有收藏等记录会保留为离线。内容相同的多份副本不自动合并。

缓存默认仍为 512 MB，可在设置中调整或迁移。免安装表示无需安装程序；索引和设置仍保存在用户数据目录，默认缓存仍在系统盘。
